# 🎬 Cinema Booking & Movie Explorer App

A modern, responsive web application for discovering trending cinema movies and simulating ticket bookings, powered by real-time data from **The Movie Database (TMDB) API**.

---

## ✨ Features

- **Real-Time Movie Feeds:** Fetches live popular, top-rated, and now-playing cinema releases.
- **Dynamic Search & Filtering:** Quick search bar and category filters to browse movies seamlessly.
- **Interactive Details View:** Displays movie overviews, ratings, release dates, and posters.
- **Booking Simulation:** User-friendly workflow to reserve seats and view ticket summaries.
- **Responsive Interface:** Clean, mobile-friendly UI optimized for modern devices.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+ Modules), HTML5, CSS3
- **Data & APIs:** TMDB RESTful API, Fetch API (Async/Await)
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

Follow these steps to run the application locally on your machine:

### 1. Clone the repository
```bash
git clone [https://github.com/Belal-Kogek/Cinema-Booking-APP.git](https://github.com/Belal-Kogek/Cinema-Booking-APP.git)
cd Cinema-Booking-APP
2. Configure API Key
Create a config.js file in the root directory (or rename config.example.js to config.js):

JavaScript
export const API_KEY = 'YOUR_TMDB_API_KEY';
3. Run the App
Open index.html directly in your browser, or

Use the Live Server extension in VS Code for the best development experience.
